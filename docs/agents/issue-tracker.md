# Issue tracker: Linear

Issues and specs for this repo live in the Linear team `tiara-stack`.

## Conventions

- **Create an issue**: create a Linear issue in team `tiara-stack`, with the title and description provided by the skill.
- **Read an issue**: look up the supplied Linear identifier or URL and include its description, comments, labels, status, and assignee.
- **List issues**: list issues in team `tiara-stack`, applying the requested status and label filters.
- **Comment on an issue**: add a comment to the Linear issue.
- **Change status or labels**: use the team's existing workflow states and labels. Use `docs/agents/triage-labels.md` for the triage label mapping.
- **When a skill says "publish to the issue tracker"**: create a Linear issue in team `tiara-stack`.
- **When a skill says "fetch the relevant ticket"**: open the referenced Linear issue and read its comments and current state.

Use an available Linear integration for these operations. If none is available, give the user the proposed issue content or ask for access. Do not switch to local Markdown files without the user's direction.
